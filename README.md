## 📖 About

🔹 **Terraria — Helpful Hotkeys** is a powerful tool built to help you add powerful custom hotkeys to Terraria for quick-equipping, smart sorting, and fast access to items. Eliminate tedious inventory management with smart hotkeys that adapt to your playstyle and automate repetitive actions.

🔸 Whether you're a seasoned professional or just getting started, **Terraria — Helpful Hotkeys** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Terraria modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Quick Equip | Hotkeys to instantly equip armor, accessories, and weapons from inventory |
| Smart Sort | Sort chests and inventory by category with a single keypress |
| Custom Binds | Assign any action to any key combination in the mod configuration |
| Controller Support | Full gamepad button mapping support for console-style play |
